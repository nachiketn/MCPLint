# mcpsmell

A linter for Model Context Protocol (MCP) servers that detects the architecture
anti-patterns described in Rodrigues & Vas, "MCP Server Architecture Patterns
for LLM-Integrated Applications" (ICSME 2026), such as God Tools, unsanitized
resource content, synchronous long-running operations and vague tool
descriptions.

Status: pre-alpha. See `pilot/` for the feasibility study.

(Formerly MCPLint.)
